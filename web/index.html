Snake

The Snake game, running in your browser. Its Java source is compiled to JavaScript with TeaVM, and a small JavaFX shim draws it on this canvas.

Snake

Java src/sample on GitHub

Steer the snake around the 30 × 20 grid and eat pills. Each pill makes the snake one segment longer and one move per second faster, and the score is 10 points per pill. Running into a wall or into your own body ends the game. This is the game's own code from src/sample, running on a minimal JavaFX shim.

The snake starts at a random cell heading up. A reversed direction runs the head into the body, as in the original. The score, speed and length come from the game's own Score: text on the board.

The game's timer is JavaFX's AnimationTimer, here driven by requestAnimationFrame, so the top speed is one move per display frame, as on the desktop.
